Methodological design

Cross-validation uses stratified 5-fold partitions to maintain identical normal-to-attack ratios across all iterations. Balanced bootstrapping is applied strictly to training folds to address minority attack representation; holdout test partitions remain untouched to reflect operational network conditions.

Principal component analysis

Projection of 61 dimensions onto orthogonal axes. The first two components capture 67.31% of cumulative flow variance (and 6 components capture 91.03%), separating high-velocity flooding from benign sessions in 2D space without label leakage.

Unsupervised K-means clustering

Inertia elbow and silhouette analysis (0.7117 peak) establish optimal partitioning at K=3, isolating a 99.06% malicious bot cluster alongside mixed behavioral flow profiles.
